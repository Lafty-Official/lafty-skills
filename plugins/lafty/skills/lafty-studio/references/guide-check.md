### 6-2. 게시 전 체크리스트

**캐릭터**
- [ ] 검사에 수정할 항목이 없고, 경고는 의도한 것뿐이다
- [ ] 플레이어에 대한 정보(이름, 과거, 함께한 일)가 카드에 없다
- [ ] 첫 인사·첫 메시지가 계기를 보여 주고 물음표로 끝나지 않는다
- [ ] 확정된 사실에 일하는 시간, 쉬는 날, 맡은 일의 기간이 있다
- [ ] '대화에 근거가 있어야 하는 것'에 함께한 과거, 상대의 행동·감정·동의, 맡은 일의 결과가 있다
- [ ] 이야기에서 늦게 밝힐 사실이 지나온 이야기·세계 설정에 없다
- [ ] 실사풍이 아닌 프로필 그림이 있다

**작품**
- [ ] 메인 캐릭터를 게시했거나, 게시 창의 '캐릭터도 함께 게시'를 켰다
- [ ] 정보 탭의 한 줄 소개·소개글, 배역의 역할, 무대, 예고 문구, 챕터·이벤트 제목에 앞일의 단서가 없다
- [ ] 시작 상황에 두 사람이 아는 것과 모르는 것이 있다
- [ ] 진행 단계의 '일어나는 일'이 눈에 보이는 행동 하나다
- [ ] 모든 갈림길에 기본 경로가 있다
- [ ] 제작자 선택지가 그대로 보낼 수 있는 말이다
- [ ] 날짜가 정해진 장면에 정해진 시각이 있고, 시작 시각이 캐릭터의 일과·영업시간과 맞는다
- [ ] 첫 챕터부터 나오는 인물의 비밀에 '비밀이 처음 나올 수 있는 이벤트'가 있다
- [ ] 2차 창작이면 등급이 전체·15세이고 태그에 '2차 창작'이 있다
- [ ] 갤러리에 실사풍 그림이 없다
- [ ] 19로 게시하면 내릴 수 없다는 것을 알고 등급을 골랐다
- [ ] 스토리 테스트를 엔딩까지 한 번 했다

## 7. 잘 안 될 때

테스트에서 본 증상으로 찾아요. 대부분 실제 테스트 플레이에서 나온 것이에요.

| 증상 | 흔한 원인 | 수정할 항목 |
|---|---|---|
| 2~3턴 만에 반전이나 결말을 말한다 | 앞일이 늘 가는 항목(배역의 역할, 무대, 지나온 이야기, 세계 설정)이나 제목에 있다 | 비밀, 이벤트 설정, 연출 안내로 옮긴다 |
| 플레이어만 아는 일을 메인이 자기 기억처럼 말한다 | '처음부터 아는 것'에 플레이어 혼자 겪은 일이 있다 | 그 내용을 프롤로그로 옮긴다 |
| '지난번에 같이…'처럼 없던 과거를 지어낸다 | 시작 상황(만남이면 시작 상황과 처음부터 아는 일)에 아는 것·모르는 것이 없다 | '오늘 처음 만난다', '같이 밥을 먹은 적은 없다'를 쓴다 |
| 카드의 사실이 깨진다(사는 곳, 학년 수, 물건 위치) | 숫자나 위치가 정해져 있지 않다 | 확정된 사실·세계 설정·이벤트 설정에 숫자와 위치로 쓴다 |
| 쪽지 문구, 이름이 장면마다 바뀐다 | 설정에 원문이 없다 | 이벤트 설정에 그대로 쓴다 |
| 카드의 비밀을 엉뚱한 단역이 먼저 말한다 | 늦게 밝힐 사실이 카드의 세계 설정에 있다(늘 감) | 카드에서 빼고 이벤트 설정이나 비밀로 옮긴다 |
| 이벤트가 열리지 않는다 | 조건이 막혔거나, 여는 쪽이 '플레이어의 말로 시작'인데 플레이어가 꺼내지 않았다 | 조건을 확인하고, 앱이 열어야 하는 일은 '자동으로 시작'으로 |
| 진행 단계가 안 넘어가거나 아무 때나 넘어간다 | '일어나는 일'이 마음 상태이거나, 한 단계에 두 일이 있다 | 눈에 보이는 행동 하나로 나눈다 |
| 챕터가 끝나지 않는다 | 끝내는 이벤트가 모두 표시를 요구한다 | 표시 없는 기본 경로 이벤트를 더한다 |
| 날짜가 정해진 장면이 엉뚱한 날 열린다 | 정해진 시각이 없다(설정에만 날짜가 있음) | 이벤트의 정해진 시각을 쓴다 |
| 서브 이벤트 장면이 사라졌다 | 챕터가 넘어가 놓침으로 닫혔다 | 꼭 봐야 하면 메인으로 바꾸거나 챕터 최소 턴을 늘린다 |
| 관계가 첫 단계에서 오르지 않는다 | 진입 조건이 엄격하고 이야기가 짧다 | 챕터 최소 관계 단계, 진입 조건을 보이는 일로 |
| 메인이 결정적인 한 수를 가져간다 | 진행 단계의 주어가 메인이다 | 플레이어가 움직일 자리까지만 단계로 쓴다 |
| 연출 안내의 대사를 상황과 상관없이 말한다 | 안내에 대사가 길게 있다 | 안내는 방향 위주로, 대사는 한 줄만 |
| 말버릇을 매번 반복한다 | 말버릇이 많거나 예시 대화가 한 버릇에 몰렸다 | 말버릇 2~3개, 예시 상황을 다양하게 |
| 답장마다 질문으로 끝난다 | 쓰지 않는 말에서 '모든 답 끝의 질문'을 지웠다 | 기본 네 가지를 되살린다 |
| 표정이 과하다 | 비슷한 표정의 기준이 없다 | '언제 쓰는지'를 쓴다 |
| 그림이 안 나온다 | 이름이 다르다('당황'/'당황함') | 이름을 맞추고 '에피소드에 이름 넣기' |
| 호감도 수치가 관계와 어긋난다 | '관계 단계 따라감'이 꺼져 있다 | 켜거나, 수치를 다른 축으로 |
