# 아이디어에서 시작할 때

작가가 소설 없이 아이디어나 메모만 줬을 때 설계서를 채우는 방법입니다. 질문은 많아도 여섯 개입니다. 작가가 이미 말한 것은 묻지 않습니다.

## 한 줄만 받았을 때

바로 묻지 말고 방향이 다른 안 세 개를 먼저 냅니다. 안마다 세 줄입니다.

```
A. {메인 한 줄} / {사용자는 누구} / {어떤 재미로 끝나는지}
```

세 안은 메인의 성격이나 관계의 긴장이 서로 달라야 합니다. 같은 안의 말만 바꾼 것은 안 됩니다. 사용자의 설정을 정하지 않아도 서는 안을 추천합니다. 작가가 고르거나 섞으면 그때 남은 것을 묻습니다. 세 안은 설계서 12절에 남깁니다.

## 질문 여섯 개

한 번에 한 묶음으로 묻습니다. 질문마다 예시 답을 하나 달고, 「맡길게요」로 넘길 수 있다고 알립니다. 맡긴 칸은 지어내고 설계서 12절에 적습니다.

1. **무엇을 만드나요?** 캐릭터만 / 작품. 고르기 어려워하면 짧게 설명합니다.
   - 캐릭터만 만들면 독자가 캐릭터 페이지에서 그 캐릭터와 DM으로 대화합니다. 만들기 쉽습니다.
   - 작품은 장과 갈림길과 엔딩이 있는 스토리입니다. 메인과의 DM도 그 캐릭터의 것이라 함께 열립니다.
2. **메인은 어떤 사람이고 어떻게 말하나요?** 하는 일, 매력, 말투 한 줄이면 됩니다.
3. **사용자는 누구로 들어가고, 둘은 어떻게 시작하나요?**
4. **어떻게 끝나나요?** 스토리일 때만 묻습니다. 결말이 안 정해졌으면 「어떤 기분으로 끝나면 좋겠어요?」로 묻습니다.
5. **등급은요? 다른 작품의 캐릭터나 세계를 빌렸나요?** 전체 / 15세 / 19세. 2차 창작은 19가 될 수 없습니다.
6. **꼭 넣고 싶은 장면과 넣기 싫은 것이 있나요?**

## 맡겼을 때의 기본값

| 칸 | 기본값 |
|---|---|
| 만들 것 | 작품 |
| 등급 | 전체 |
| 장 | 3장, 장마다 메인 장면 1~2개, 서브 이벤트 0~1개 |
| 엔딩 | 3개: 갈림길 표시마다 하나씩 둘, 표시 없이 가는 기본 경로 하나 |
| 관계 | 4~5단계, 마지막 단계만 두 사람의 말이 필요 |
| 시점 | 사용자 1인칭 |

## 아이디어를 살리는 법

- 라벨을 조건과 반응으로 바꿉니다. 「츤데레」는 「고맙다는 말을 들으면 '딱히 너 때문은 아니고'를 먼저 붙인다」처럼 씁니다.
- 작가의 표현을 버리지 않습니다. 작가가 쓴 단어와 장면을 설계서에 그대로 살립니다.
- 빈 곳을 메울 때 흔한 설정으로 평균을 내지 않습니다. 가게 이름, 동네, 숫자처럼 작품에만 있는 것을 정합니다.
- 소설처럼 깊은 작품을 원하면 lafty-novel로 소설을 먼저 쓰는 길을 권합니다.
