# 7단계: 작품설계서로 옮기기

`story-sheet.md`의 틀에 맞춰 씁니다. 설정집과 대강이 있으므로 다시 만들지 않고 옮깁니다.

| 설계서 | 가져올 곳 |
|---|---|
| 1 작품 | `방향.md`. 한 줄 소개와 소개글에서 반전을 뺍니다 |
| 2 메인 | 설정집의 인물 카드. 대표 대사는 본문에서 그대로 3~5줄 |
| 3 조연 | 설정집. 서브 하나, 엑스트라 다섯까지 |
| 4 사용자 | 소설의 주인공. 이름은 기본 이름으로, 혼자 겪은 일은 「사용자만 아는 것」으로 |
| 5 세계 | 설정집과 본문의 숫자, 이름, 날짜 |
| 6 진실표 | 설정집의 진실표 |
| 7 관계 변화 | 관계표의 단계. 마지막 고백 단계만 두 사람의 말이 필요 |
| 8 이야기 줄기 | 대강의 화를 장으로, 장면을 표로 |
| 갈림길, 9 결말 | 대강의 갈림길 표와 결말 후보 |
| 10 문체 견본 | 1화 첫 장면을 사용자의 자리에서 다시 쓴 글. 주인공(사용자)의 말과 행동은 빼고 보고 듣는 것만 남깁니다. 주인공 시점이라 남는 것이 적으면 같은 장면을 새로 씁니다 |
| 11 DM과 그림 | 소설 밖에서 메인과 처음 연락하는 만남 하나. 복선 물건은 장면 그림 후보 |
| 12 확인할 것 | 소설에 없어서 새로 정한 것, 작가의 판단이 필요한 것 |

## 옮길 때 주의

- 주인공의 말과 감정은 설계서에 쓰지 않습니다. 사용자의 몫입니다.
- 「꼭 일어나는 일」은 눈에 보이는 행동 하나로, 줄거리가 넘어가는 문턱만 씁니다. 한 번 놀 때 16~22개입니다. 소설의 세세한 동작은 살릴 디테일 칸으로 보냅니다. 주어를 씁니다.
- 주인공의 결정적 행동은 메인의 일로 옮기지 않습니다.
- 살릴 디테일 칸에 소설의 물건과 말을 적습니다. 작품의 맛이 여기서 납니다.
- 장을 끝내는 장면은 연출이 엽니다. 카드에 갈 칸(2절)에는 진실표의 내용과 앞일의 날짜를 쓰지 않습니다.
- DM은 소설의 뒷이야기가 아닙니다. 만남에 소설의 사건을 쓰지 않습니다.
- 소설 문장을 칸에 길게 옮기지 않습니다. 방향을 쓰고 대사는 한 줄만 씁니다.
